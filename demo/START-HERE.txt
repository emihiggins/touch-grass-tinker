LIFT-LAP PLANNER — LOCAL SIMULATION DEMO

Requirements: Python 3.11 or newer and a current browser. No installation of
Python packages, API key, model download or paid account is needed.

1. Extract the entire ZIP into a new folder. Do not run it inside the ZIP viewer.
2. Open a terminal in the extracted folder (the folder containing liftlap/).
3. Run:
     python3 -m liftlap.server --port 8767
   On Windows, use this if python3 is not available:
     py -3 -m liftlap.server --port 8767
4. Open http://127.0.0.1:8767 in a browser on that same computer.
5. Stop the server with Ctrl-C when finished.

FIRST OUTING
Choose Load example request, then Recorded AI example. Review constraints.
The saved AI output softens “no drag lifts” incorrectly: check t-bar, platter
and rope-tow as hard exclusions, then Confirm & plan outing. This demonstrates
local correction, not another model call. Recorded AI only works for the exact
example. Rules mode supports a limited grammar and works without a provider.

REAL-GEOMETRY VIEW
Choose Alpendorf, then Open geographic map. Its local hillshade and trail lines
work offline. If the graphics renderer is unavailable, use the SVG sketch.
All terrain remains unreviewed; the shading is not snow or slope-safety data.

TROUBLESHOOTING
If the port is in use, choose another, e.g. --port 8768, and open that port's URL.
If Python is missing or older than 3.11, install/update it first.
If a browser cannot connect, leave the terminal running and use the URL on the
same computer. The server intentionally binds to loopback; don't expose it as a
public site. No phone/network-hosting configuration is part of this demo.

IMPORTANT
This is a simulation/research prototype, not real ski navigation. No live lift
status, verified access, avalanche assessment or field validation is included.
Live AI is disabled. The archive does not contain credentials or model weights.
